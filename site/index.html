How it works

From ROM to standalone game

  1. 1

    Add your games

    Drop ROMs, ZIPs, arcade romsets, disk images or mixed folders. Console detection sorts recognized games automatically.

  2. 2

    Convert

    Game code is recompiled into a native executable and checked against a reference CPU. Up to eight conversions run at once.

  3. 3

    Play

    Launch the generated game directly. No Python, no separate ROM file and no external SDL2 DLL are needed to play.

Console support

Nine console profiles

Compatibility depends on the game and its exact revision. The 16-bit profiles analyze new games automatically; there is no fixed game list.

Master System

Two players, PAL/NTSC, quick states and Light Phaser.

Game Gear

Native handheld display and colors.

Game Boy

Original Game Boy, quick states, grayscale or classic green.

NES

Validated cartridge layouts, PAL/NTSC, quick states and Zapper.

Mega Drive

Standard cartridges, PAL/NTSC, SRAM and supported EEPROM, quick states and Menacer.

Super Nintendo

Standard LoROM/HiROM cartridges, PAL/NTSC, quick states, battery saves and Super Scope.

Neo Geo

Arcade MVS with optional console AES, two players, scores, memory card and quick states.

Capcom CPS-1

Experimental: MAME/FBNeo romsets of the standard boards, up to four players and six buttons, DIP switches, rotated vertical games, quick states.

Sharp X68000

Experimental: DIM/XDF disks and multi-disk sets, your own IPL and font ROM, quick states, mouse and keyboard.

Limits for each profile are listed in the compatibility guide.

Play. Learn. Recompile.

Native from the first export

The goal is native execution from the first export, without interpreter fallback. When a game does reach code that conversion checks have not covered, the interpreter fallback is used and stays visible in the game.

The game then collects small hints in memory and saves them when you close it. RetroRecomp checks those hints against the exact game and uses them on the next regeneration to reduce fallback. Graphics and hardware issues still need fixes in the runtime itself.

Verified hints for 1,305 exact game identities ship with the converter, the whole convertible Neo Geo library among them. Your own discoveries stay in your local library, and you can share them as one ROM-free file: only addresses and positions in the ROM travel, never ROM bytes.

Features

Built for a whole collection

Batch conversion

Convert a whole list or only the selected games. Unfinished games come back after an interruption.

Only what needs it

Up-to-date games are skipped; when an update only changes menus or presentation, games are upgraded without rediscovery.

A living collection

Favorites, covers and summaries, kept current without rescanning: discoveries saved when a game closes appear at once.

New paths

One button recompiles only the games whose play found new paths; closing the app offers the same.

One menu everywhere

F2 pages for controls and options, the same filters and fullscreen modes, F8/F9 quick states on every console.

Eight languages

The converter speaks English, French, Italian, Spanish, German, Japanese, Chinese and Russian; games the first five (F7).

Optional enhancements

Fewer flickering sprites on Master System and Game Gear, no eight-sprite limit on NES, more CPU headroom on Neo Geo.

Lightgun games

Mouse aiming for supported Light Phaser, Zapper, Menacer and Super Scope games.

What we measure

Native is not the same as exact

RetroRecomp keeps these measures separate. Native execution alone does not guarantee complete compatibility or zero latency.

Native code
How much of the game runs as recompiled code rather than through the interpreter fallback.
CPU agreement
Whether recompiled code matches a reference CPU on the tested paths.
Hardware fidelity
How closely video, audio and timing follow the original machine.
Gameplay testing
Sampled play sessions. They do not cover every path of every game.
Physical latency
Not established by native execution. No zero-latency claim is made.

Get started

Three steps

  1. Download the Windows setup EXE or the Linux x86-64 .run installer from the latest release. Portable downloads are also available.
  2. Add your ROMs or folders, leave console detection on Automatic, and convert.
  3. Open the generated games in their console folders under Games, next to the app.

Conversion needs a supported build toolchain; see the setup guide. Playing exported games needs no development tools. ROMs and box art are not included. The Linux package is checked on Debian 13; other distributions still need testing.
