# Mega Drive: synchronous MC68000 exceptions

The instruction translator handles privileged instructions attempted in user
mode, zero-divisor DIVU/DIVS, signed-word CHK, conditional TRAPV,
ILLEGAL (`$4AFA–$4AFC`), line-A and line-F traps, and instruction tracing.
An exception enters its own ROM vector through native code, rather than silently
continuing or stopping the host. A live RAM byte mismatch still uses counted
fallback. This work does not complete the Mega Drive hardware profile.

## Architectural behavior

- The original MC68000 six-byte frame stores SR and PC on the supervisor stack;
  the user stack is retained. Trace is cleared in the handler's SR, while the
  previous interrupt mask is preserved.
- Privilege and illegal/line traps store the faulting instruction address.
  Division by zero, CHK, TRAPV and TRAP store the following instruction address. RTE reads
  both fields before selecting the restored stack.
- Privilege checks precede operand access, including postincrement MOVE to SR.
  MOVE **from** SR remains available in user mode on MC68000; the later 68010
  restriction is not applied. User-mode RESET takes the privilege vector;
  supervisor RESET's external-device wiring remains unsupported.
- Illegal, privilege and TRAP entry cost 34 clocks. Zero divide costs 38 plus
  its effective-address cost. Immediate SR/CCR operations cost 20 clocks;
  MOVE to SR costs 12 plus its effective-address cost; MOVE from SR costs 6 to
  a register, or 8 plus its effective-address cost to memory. Exception cost is consumed
  before scheduler/IRQ entry and never becomes a persistent snapshot latch.
- CHK reads its bound once and compares signed 16-bit values, retaining the
  full destination register. It takes vector 6 on an invalid interval; TRAPV
  takes vector 7 only with V set. CHK entry is 38 or 40 clocks plus EA, depending
  on the comparison path (including subtraction overflow); its non-trap path
  is 10 plus EA. TRAPV costs 34 clocks when taken, otherwise 4.
- Trace samples T at instruction entry. A completed instruction takes vector 9
  before the scheduler can deliver a pending interrupt. An instruction trap is
  stacked first, then trace; illegal and privilege faults suppress trace. Setting
  T does not trace the same instruction; clearing it during an instruction does
  not cancel an already requested trace. RTE and STOP use the same rule.
- An IRQ handler executes nested exception returns and stops only after its
  original supervisor-stack frame is popped. It no longer stops at the first
  nested RTE or executes an extra instruction after its own return. This does
  not qualify every interrupt arbitration or mid-instruction bus event.
- Guarded RAM bodies retain the actual alias PC for saved addresses and
  PC-relative operands. A physical opcode variant is shared across RAM mirrors.

Unknown decoder patterns and unsupported later-CPU operations remain explicit
limitations. They are not automatically reclassified as a supported illegal
instruction. Address/bus-error frames and electrical interrupt scheduling remain
separate qualification work.

## Independent verification

[Motorola's MC68000 manual](https://www.nxp.com/docs/en/reference-manual/MC68000UM.pdf),
sections 6.3.5–6.3.8 and tables 8-12/8-14, specifies the frames, saved PC and
clock costs used by the authored tests. The tests exercise native and reference
paths, including all 32 work-RAM aliases, single EA access and RTE recovery.
Divide-by-zero CCR results and CHK's undefined flag bits use a deterministic
software convention; these tests do not claim physical fidelity for those bits.

`python tools/megadrive_exception_selftest.py` checks **864 synthetic cases** from
[SingleStepTests/m68000](https://github.com/SingleStepTests/m68000/tree/64b253116a3de04aaac4346c43680960dc9b67e5),
pinned to `64b253116a3de04aaac4346c43680960dc9b67e5`. Each is run through the
emitted native body and the separately decoded reference path. Registers, listed
memory (including frames), supervisor/user stacks and total CPU/audio clocks
must match the external expected results.

The corpus is MIT-licensed, generated by MAME rather than physical hardware.
The fixture retains its original values, case names, source hashes and license.
Its PC includes two prefetched words: the harness converts it to an architectural
PC and the 24-bit bus. A stopped supervisor STOP does not prefetch again, so its
final PC already points to the following instruction. Prefetch contents and bus
transaction order are outside this comparison. The flat test bus isolates CPU
behavior; it does not establish the console's I/O timing or memory map.

The 96 added CHK cases include valid bounds and traps in both privilege modes,
register and memory forms, pre/postincrement and both trap timing paths.
The single-step oracle does not emit post-instruction trace delivery; its T-set
cases cannot validate that boundary. Trace, odd-address/bus errors, TAS/TRAPV
and nonzero divide timings remain excluded from this external comparison.
Independent authored cases in `tools/megadrive_native_selftest.py` cover trace,
TRAPV and zero divide using the manual, including the TRAP → trace → IRQ order,
SR transitions, nested RTE and all 32 RAM aliases. These scopes are distinct;
excluded external cases are not counted as passing cases.

Cartridge CPU/memory/video/PCM agreement remains an additional internal
regression check. It cannot replace the independent cases, user gameplay
review or physical latency measurements. Compilation hints may be shared only
after the usual exact-ROM qualification; test fixtures and player data are not
included in the game's or converter's compilation-knowledge snapshot.

The subsequent ordinary-instruction timing work adds
`tools/megadrive_cycles_selftest.py`: 55 authored native/reference cases with
literal clock expectations from Motorola manual tables 8-5 through 8-8. These
cover previously misidentified memory EAs, directional ALU costs, byte-bit
operations, quick operations on address registers, memory shifts, CMPM and
memory extend/BCD operations. Byte CMPM on A7 retains its word increment. CLR/Scc
also retain their discarded read and a single address-register update. This
flat-bus suite isolates total clocks and side effects. It does not qualify the
prefetch queue, internal cycle placement, variable multiply/divide timings or
Genesis electrical bus arbitration.

The separate [prefetch and transaction suite](MEGADRIVE_PREFETCH.md) now checks
2,089 external cases including selected exception, privilege, RTE and variable
arithmetic phases, plus 82 separately authored arithmetic/DBcc limits.
It compares ordered frame/vector/prefetch transactions and their cumulative
clocks, beyond the register/total-clock scope of the 864-case suite above.
Authored trace and 44-clock autovector tests add explicit phase expectations.
The actual console backend verifies suspend/resume before and after interrupt
acknowledge, without replaying frame writes or allowing an incomplete F8 snapshot.
These scopes do not establish bus/address-error frames or electrical IRQ timing.
